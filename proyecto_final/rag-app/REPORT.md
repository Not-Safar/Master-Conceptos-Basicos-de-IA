# Aula RAG


**Propósito y documentos.** Aula RAG permite consultar documentos sobre fundamentos de inteligencia artificial, aprendizaje automático, embeddings y sistemas RAG. Su objetivo es ofrecer respuestas que puedan comprobarse al leer las fuentes. La colección de ejemplo reúne cinco documentos Markdown originales, compartidos bajo licencia CC0, con 3,926 palabras. Después de procesarlos, se obtuvieron 18 fragmentos de texto, llamados chunks, que forman el índice de búsqueda.

**Organización y búsqueda del texto.** Los documentos se dividen en fragmentos de hasta 300 palabras, con un solapamiento de 60 palabras. Esta repetición ayuda a conservar el contexto cuando una explicación queda entre dos fragmentos. El tamaño elegido permite encontrar pasajes concretos sin enviar documentos completos al modelo, aunque aumenta la información repetida. Cada fragmento guarda el archivo de origen y su posición; en los PDF se respeta el límite de cada página. Para responder una pregunta se recuperan cuatro fragmentos por defecto, cantidad que puede ajustarse entre uno y diez. La búsqueda usa similitud coseno: el valor mostrado indica cercanía entre vectores, no la certeza de una respuesta.

**Funcionamiento del sistema.** Google AI convierte los documentos y las preguntas en vectores mediante gemini-embedding-001, con 768 dimensiones normalizadas. Se mantiene el mismo modelo para ambos tipos de texto. ChromaDB guarda esos vectores junto con los fragmentos y sus datos de origen, y permite buscar los más cercanos a cada pregunta. Después, Gemini redacta una respuesta en español usando el contenido recuperado e incluye citas numeradas. La configuración probada utiliza gemini-3.8-flash. FastAPI coordina estas tareas y Streamlit permite cargar archivos, hacer preguntas y revisar las fuentes mediante peticiones HTTP a la API.

**Criterio para responder.** Si el índice está vacío o ningún fragmento alcanza una similitud de 0.35, el sistema indica que no tiene información suficiente. Cuando sí hay resultados, Gemini debe comprobar que permiten responder toda la pregunta y abstenerse si falta algún dato. La API revisa que las citas correspondan a los fragmentos enviados al modelo. Esta comprobación evita referencias inexistentes, pero no sustituye la lectura de las fuentes para confirmar que respaldan la respuesta. El umbral es un punto de partida y puede requerir ajustes con otros documentos.

**Resultados y alcance.** Se aprobaron 68 pruebas locales con Chroma real y llamadas a Google simuladas solo para esas pruebas. En la evaluación con Google real, tres preguntas sobre los documentos recibieron respuestas con citas revisadas y dos preguntas sobre datos ausentes produjeron abstención. También se comprobó que reiniciar la API conserva los cinco documentos y sus 18 fragmentos. Las capturas, los resultados y el registro del reinicio acompañan la entrega. La aplicación necesita una clave propia y cuota disponible en Google AI; los PDF que contienen únicamente imágenes requieren una herramienta adicional para extraer su texto.
